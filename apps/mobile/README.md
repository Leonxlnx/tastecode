# TasteCode for iPhone

The phone client: Expo with SwiftUI through [`@expo/ui`](https://docs.expo.dev/versions/latest/sdk/ui/swift-ui/),
Liquid Glass on iOS 26 and later. It pairs with the desktop and speaks the same protocol over an
end-to-end encrypted link (see "Phones connect over an end-to-end encrypted link" in
`docs/ARCHITECTURE.md`).

This folder is outside the pnpm workspace and has its own npm install, so React Native and
CocoaPods never enter the desktop's install. Its TypeScript imports the shared contracts' types
from `packages/contracts/src`, which needs the repository's `pnpm install` once.

## Run it

Needs Xcode 26 or later, CocoaPods (`brew install cocoapods`) and Node 22.

```bash
cd apps/mobile
npm install
npx expo run:ios                 # builds, installs and starts Metro for the simulator
npx expo run:ios --device        # a connected iPhone; pick a signing team in Xcode first
```

`ios/` is generated by `npx expo prebuild` from `app.json` and the local modules; never edit it by
hand. After changing Swift in `modules/`, build again.

## Pair

1. On the computer, open TasteCode › Settings › Phone, turn on phone access and choose
   **Show pairing code**.
2. In the app, choose **Scan Pairing Code** (or scan with the Camera app, or copy the link and
   choose **Paste Pairing Link**).

The phone and the computer must share a network: the same Wi-Fi, or a Tailscale tailnet, which
also works away from home. The listener uses port 4317 (`HARNESS_PHONE_PORT`).

## Layout

| Path                     | What it holds                                                        |
| ------------------------ | -------------------------------------------------------------------- |
| `modules/tastecode-link` | The link in Swift: Noise IK (CryptoKit), Keychain, Network.framework |
| `modules/tastecode-ui`   | SwiftUI views Expo UI lacks: Markdown replies, chat scaffold, QR     |
| `src/link`               | Pairing links and the protocol connection, with its reconnect rules  |
| `src/state`              | Projects, model sources, open chats and their event reducer          |
| `src/ui`                 | The screens, written with `@expo/ui/swift-ui`                        |

`src/link` and `src/state` have no iOS code; an Android build adds a Kotlin `TasteLink` module
with the same functions and events, and a Jetpack Compose view layer.
